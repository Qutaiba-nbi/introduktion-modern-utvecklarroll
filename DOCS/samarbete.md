# Repository-samarbete

Ett gemensamt repository används av ett utvecklingsteam för att lagra och versionshantera ett projekt tillsammans.

Varje utvecklare kan arbeta med projektet på sin egen dator och sedan skicka sina ändringar till repositoryt. Git gör det möjligt att se vilka ändringar som har gjorts och att samarbeta kring projektet.

Ett gemensamt repository kan innehålla kod, dokumentation och andra filer som behövs i projektet. GitHub kan användas som en central plats där teamet delar projektet.

Branches kan användas när olika utvecklare arbetar med olika funktioner. När arbetet är klart kan ändringarna slås ihop med projektets huvudbranch.
