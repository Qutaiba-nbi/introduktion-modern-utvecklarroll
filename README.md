# Introduktion till modern utvecklarroll

Det här projektet är en praktisk verktygsövning från kursen Introduktion till modern utvecklarroll.

Under uppgiften tränar jag på grundläggande utvecklingsverktyg och arbetsflöden. Jag använder terminalen för att skapa och navigera mellan mappar och filer. Jag använder även Visual Studio Code för att skriva och redigera filer samt Git och GitHub för versionshantering.

## Syfte

Syftet med uppgiften är att få en grundläggande förståelse för terminalen, Visual Studio Code, Git, GitHub och repository-samarbete.
