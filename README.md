# Introduktion till modern utvecklarroll

Det här projektet är en praktisk verktygsövning från kursen Introduktion till modern utvecklarroll.

Under uppgiften tränar jag på grundläggande utvecklingsverktyg och arbetsflöden. Jag använder terminalen för att skapa och navigera mellan mappar och filer. Jag använder även Visual Studio Code för att skriva och redigera filer samt Git och GitHub för versionshantering.

## Syfte

Syftet med uppgiften är att få en grundläggande förståelse för terminalen, Visual Studio Code, Git, GitHub och repository-samarbete.
## Git-kommandon

Under uppgiften använder jag följande Git-kommandon:

* `git init` – skapar ett nytt Git-repository.
* `git status` – visar statusen på projektet och vilka filer som har ändrats.
* `git add` – lägger till ändringar som ska vara med i nästa commit.
* `git commit -m "meddelande"` – sparar ändringar som en version i Git-historiken.
* `git log` – visar tidigare commits och versionshistoriken.
* `git remote` – hanterar kopplingen till ett repository på exempelvis GitHub.
* `git branch` – används för att hantera branches.
* `git push` – skickar commits från datorn till GitHub.
* `git pull` – hämtar ändringar från GitHub till datorn.
